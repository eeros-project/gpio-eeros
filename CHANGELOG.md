## v1.0.0
(2026-05-13)

### Notes
This is the first official release. The gpio-eeros wrapper library enables the
usage of the standard gpio subsystem together with the [EEROS Robotics Framework](http://eeros.org).

### Features
* **DigIn:** Read the pause and mode buttons and the GPIOs
* **DigOut:** Set the green and red leds and the GPIOs
